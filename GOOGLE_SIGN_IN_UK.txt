ВХІД GOOGLE — LOWTUBE 0.5
Збірка підтримує офіційний Google OAuth для ПК через звичайний браузер.
Готового зареєстрованого Client ID у ній немає. Перед першим входом
потрібно одноразово налаштувати власний проєкт Google Cloud.

1. Відкрий https://console.cloud.google.com/ і створи або обери проєкт.
2. APIs & Services > Library: увімкни YouTube Data API v3.
3. Відкрий Google Auth Platform. Заповни Branding: назва програми та
   контактна пошта. У Audience для особистої перевірки обери External /
   Testing і додай свою адресу Google до Test users. Для Workspace
   доступ може обмежувати адміністратор.
4. У Data Access додай https://www.googleapis.com/auth/youtube.readonly .
5. Clients > Create client > Desktop app. Завантаж JSON клієнта.
   Не обирай Web application, Android або ключ service account.
6. У LowTube: Акаунт > Імпортувати JSON клієнта OAuth. Обери цей файл.
7. Натисни «Увійти через Google». Вибери акаунт на accounts.google.com
   і дозволь читання YouTube. Після перенаправлення повернись у LowTube.
8. Відкрий «Підписки Google» зліва. Список каналів читається через
   офіційний API, останні публічні відео — зі стрічок каналів.
   Зчитуються всі сторінки підписок; показується до 3000 останніх відео.
   Локальні підписки незалежні та не перезаписуються.

У проєктах Testing зазвичай треба повторювати вхід через сім днів.
Вимкнений API, вичерпана квота, політики адміністратора чи відкликаний
дозвіл можуть блокувати доступ. Використовуй власний OAuth-проєкт.
Для широкого розповсюдження потрібні відповідні процедури публікації
та перевірки Google; ця збірка не має верифікації Google.

OAuth не надає персональну головну стрічку, історію переглядів чи адреси
для скачування медіа. Рекомендації залишаються тематичними; локальна
історія — історія цього клієнта. Попередня експериментальна історія
YouTube та відтворення з акаунтом доступні через Акаунт > Налаштування
Firefox / cookies. OAuth-токени не передаються в yt-dlp, mpv, запити
прев'ю чи публічних стрічок каналів.

Токени зашифровані DPAPI для твого користувача Windows у файлі
%LOCALAPPDATA%\LowTube\google-session.bin. Налаштування клієнта —
google-client.json. Пароль вводиться лише на сайті Google.
Відключення видаляє локальний токен. «Відкликати доступ Google» також
забирає дозвіл у цього OAuth-клієнта; підписки не змінюються.
Дозволи також доступні на https://myaccount.google.com/connections .
Закриття вікна або скасування зупиняє вхід; час очікування — п'ять хвилин.

Повний вхід із реальним Google потребує твого клієнта та акаунта і ще
не перевірений наживо в цій збірці. Локальне перенаправлення, state,
PKCE, скасування й компіляцію перевірено; автоматичні тести — у tests/GoogleTests.cs.
