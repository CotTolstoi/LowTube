LowTube 0.11.6 — повний проєкт без сторонніх залежностей та даних користувача
Дата пакування: 2026-10-17.

1. Розпакуйте папку LowTube в окремий каталог.
2. Запустіть SETUP.cmd з доступом до інтернету: він викликає Setup.ps1 та встановлює mpv, FFmpeg/FFprobe, yt-dlp, Node.js і QuickJS. Setup.exe у цьому проєкті немає.
3. Запустіть START.cmd. Для спільного повторного збирання всіх чотирьох EXE використайте Build-All.ps1.

Потрібні Windows 10 x64, .NET Framework 4.8 та Windows PowerShell 5.1.
Включено поточний код, тести, документацію, ліцензії, чотири власні EXE та окремий hybrid-експеримент.
Сторонні EXE/DLL, каталог tools, download-cache, профілі браузерів, cookies, OAuth credentials, історія, черга, налаштування та інші дані користувача не включені. Локальний setup-diagnostics.txt і дублюючий ZIP-патч також не вкладені.
Дані програми в %LOCALAPPDATA%\LowTube не читалися й не копіювалися.
Локальні особисті шляхи в документах/маніфестах очищення замінено на C:\Projects\LowTube лише всередині архіву; робочі оригінали збережено.
Метадані встановлених залежностей скопійовано як handoff/INSTALLED_DEPENDENCIES_REFERENCE_2026-10-17.json. Це історичний опис; SETUP може завантажити новіші версії.
Історичні SHA256-маніфести описують попередні знімки. Точний поточний вміст перевіряє handoff/FULL_PACKAGE_2026-10-17_SHA256.json.

Під час пакування код не змінювався й EXE не перебудовувалися. Чотири EXE звірено з маніфестом випуску 0.11.6; PowerShell-скрипти перевірено синтаксично. Перевірено ZIP CRC, повний набір файлів, SHA256 кожного вкладення та виключення залежностей/користувацьких файлів.
Встановлення з мережі, відтворення відео, GPU й аудіо в цьому пакувальному прогоні не запускалися.
