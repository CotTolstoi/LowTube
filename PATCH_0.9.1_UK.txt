LowTube 0.9.1 — панель плеєра та розширені налаштування

ВСТАНОВЛЕННЯ
Закрийте LowTube. Скопіюйте вміст папки LowTube з патча у свою папку програми
із заміною файлів. Важливо скопіювати також player та src. Папку tools залиште.
SETUP.cmd запускати не потрібно. Патч призначений для LowTube 0.9.0.

КЕРУВАННЯ
Шестерня на нижній панелі відкриває компактне меню поверх відео:
максимальна роздільна здатність, H.264 only, до 30 FPS, швидкість,
поверх інших вікон, вікно без рамки та перехід до розширених налаштувань.
Якість — верхня межа: нижчий доступний формат можливий за обмежень кодека/FPS.
Меню працює мишею; також стрілками та Enter. Esc або клік поза меню закриває його.
F4 та права кнопка миші відкривають старий повний діалог налаштувань.
Кнопки аудіодоріжки та субтитрів прибрані. Гучність/вимкнення звуку залишені.

РОЗШИРЕНІ ПАРАМЕТРИ
D3D11 flip, D3D11 zero-copy, потоки декодера (0 = автоматично), масштабування,
пропуск кадрів, синхронізація відео, інтерполяція, усунення смуг кольору,
деінтерлейсинг, збереження тональності аудіо при зміні швидкості.
Пояснення доступні при наведенні. «Скинути параметри продуктивності» відновлює
лише нові параметри; для збереження натисніть «Застосувати».
Початкові значення зберігають попередню поведінку. Zero-copy не гарантує
прискорення на кожному драйвері; доступний лише з D3D11-рендером.
Інтерполяція потребує режиму синхронізації display-* та збільшує навантаження.
Більшість роликів YouTube не потребують деінтерлейсингу.

Швидкість і режим вікна змінюються без повторного відкриття потоку.
Якість і параметри декодування/обробки можуть повторно відкрити потік зі
збереженням позиції, паузи й гучності. Зміна D3D11 flip або рендера перезапускає
mpv для нового графічного контексту. Еквалайзер і попередні функції збережені.
При відкритті відео програма очікує створення вікна та намагається активувати
його, відновлюючи зі згорнутого стану. Це не вмикає постійний Always on top.
Windows може обмежувати передачу фокуса; перевірте на цільовій системі.

ПЕРЕВІРКИ
Зібрано Windows x64 EXE для .NET Framework 4.8 (C# 5).
283 перевірки ядра, 26 перевірок Lua, перевірка синтаксису двох Lua-скриптів
і 394 записи перекладів EN/UK/RU пройдені.
Windows GUI, фактичний фокус вікна та драйверні режими на legacy NVIDIA GPU
у цьому середовищі не перевірялися. Гарантій збільшення FPS немає.
Для діагностики START_PLAYBACK_DEBUG.cmd тепер також записує обрані параметри.

Зовнішня панель lowtube_osc.lua базується на mpv v0.41.0; вихідний код,
опис змін та ліцензія включені у player. Компоненти tools не змінювалися.
