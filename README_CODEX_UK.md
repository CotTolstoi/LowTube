# LowTube — повний проєкт для продовження в Codex

Стан на 2026-11-02: основний застосунок 0.12.3, бенчмарк 1.2, експериментальний конвеєр і порівняльний тест 0.5.

У 0.12.3 окреме аудіо задається як параметр конкретного файлу mpv, щоб під час заміни відео не залишалася аудіодоріжка попереднього елемента плейлиста. Кнопка Next в OSC плеєра та клавіша N переходять через чергу LowTube, зокрема до вже не передзавантаженого наступного елемента. Збірка чотирьох EXE і 14 цільових перевірок вибору/параметрів формату пройшли; повна перевірка обмежена блокуванням loopback-сокетів у тестовому середовищі, Lupa відсутній, реальний звуковий тест не проводився.

Для роботи з гілками, комітами, перевірками й правилами безпечного збереження файлів див. `GIT_WORKFLOW_UK.md`.

Під час запуску збережена сесія YouTube один раз оновлюється з раніше вибраного профілю браузера. Для захисту наявної сесії імпорт має містити чинні ознаки входу, що збігаються з попереднім входом; інакше потрібне повторне підключення через Account. При невдачі попередня сесія залишається, час спроби обмежено 15 секундами. Cookies не використовуються у перевірках.

Вебклієнт, кнопку його запуску та локальний сервер видалено на прохання користувача. Нативний інтерфейс LowTube залишається основним.

У 0.12.2 виправлено пропуск звичайних відео в рекомендаціях, коли сучасна InnerTube-картка не містить `contentType`; Shorts у тій самій стрічці зберігаються окремим типом. Додано регресійну перевірку змішаного результату. Повний набір `Run-Checks.ps1` пройшов; перевірка реального приватного акаунта не виконувалась.

У 0.12.1 за проханням користувача повернено інтерфейс до оформлення 0.11.6. Інструкції для 0.12.0 нижче є історичними.

У 0.12.0 головне вікно оформлено в стилі YouTube: пошук угорі, бічна панель з іконками та згортанням, фільтри-кнопки, округлені відеокартки й меню дій. Параметри декодера та журнал розгортаються кнопками; всі попередні функції, світла/темна теми й EN/UK/RU збережено. Один клік по прев'ю запускає відео; Enter і подвійний клік по заголовку також працюють. Нових залежностей немає. Звіт і знімки тестового макета: `handoff/YOUTUBE_UI_VALIDATION_UK.md`; `Run-Checks.ps1 -WindowsUi` виконує ізольовані офлайн-перевірки WinForms.

Після погодженого локального очищення видалено кеш інсталятора, тимчасові результати, старі архіви й необов'язкові vendor-файли; робочі інструменти, актуальний патч, код, тести та hybrid збережено. Node і QuickJS-NG залишаються. Deno/QuickJS Classic та їхні launchers відсутні; історичні маніфести збережено. Перелік і перевірки: `handoff/CLEANUP_DONE_2026-10-17.md`. Наступний SETUP може знову створити кеш і необов'язкові файли.

У 0.11.6 виправлено пропущений у 0.11.5 хрестик панелі OSC: він викликав quit, що могло запускати відновлення. Кнопка використовує спільний Stop, явний quit і штатний вихід після EOF скасовують відтворення; аварійна втрата процесу залишається помилкою. Перевірки: `handoff/OSC_CLOSE_VALIDATION_UK.md`.

У 0.11.5 виправлено скасування запуску/відновлення після закриття відео та вибір найближчої доступної нижчої роздільності. Збережено обмеження FPS/H.264, явний повторний запуск і звичайний перехід черги. Перевірки та межі висновків: `handoff/PLAYBACK_STOP_VALIDATION_UK.md`.

У 0.11.4 додано один контрольований повтор відкриття потоку зі свіжими посиланнями та точніші приватні діагностичні повідомлення. Ліміти якості й налаштування користувача не змінюються. Перевірки та межі висновків: `handoff/STREAM_OPEN_VALIDATION_UK.md`. Додатковий локальний native mpv тест: `Run-Checks.ps1 -WindowsMedia`.

У 0.11.3 реалізовано перший наступний етап: відновлення списків після тимчасових збоїв, пауза HTTP після 429/503, ізоляція кешу від змін у UI та зупинка пакета каналів при загальному збої. План наступних етапів і звіт 485 перевірок — `handoff/DEVELOPMENT_PLAN_UK.md`. Прискорення запуску відео відкладено.

У 0.11.2 каталог переведено на InnerTube: пошук, рекомендації, історія YouTube, канали, підписки, плейлисти, Shorts і списки трансляцій. yt-dlp залишається для потоків відео/audio-only, вибору медіаформатів, завантажень та погодженого локального експорту cookies браузера. Точні дати й метадані читаються з HTML YouTube без отримання потоків. Нових залежностей немає. Аналіз, перевірки й відомі обмеження: `handoff/INNERTUBE_VALIDATION_UK.md`.

1. Розпакуйте архів в окрему папку, наприклад `C:\Projects\LowTube`.
2. Відкрийте цю папку як робочий проєкт у Codex.
3. Передайте текст із `handoff/START_PROMPT_UK.txt` як перше завдання.
4. Код і результати попередньої роботи описані в `AGENTS.md` та `handoff/`.

## Що включено

Повний поточний код `src/`, `player/`, `benchmark/`, `hybrid/`, усі наявні тести, документація, наявні EXE власних компонентів, скрипти встановлення й запуску, нові скрипти загальної збірки та перевірок, задачі VS Code та очищені діагностичні звіти.
Початкове перенесення 0.11.1 було без функціональних змін; наступний патч 0.11.2 додає описану вище інтеграцію InnerTube.

## Залежності й збірка

Для Windows потрібні .NET Framework 4.8, Windows PowerShell 5.1. Python 3 потрібен для Python-перевірок; для частини перевірок також FFmpeg, mpv, yt-dlp або .NET SDK 8.

```
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-All.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Run-Checks.ps1
```

Великі сторонні бінарні залежності `tools/` не вкладені. Для запуску можна скопіювати **весь каталог tools** зі своєї робочої збірки LowTube або запустити `SETUP.cmd` з доступом до інтернету. SETUP завантажує компоненти й перебудовує застосунок; після нього запустіть Build-All.ps1 для тестерів.
Для точного порівняння бенчмарків використовуйте той самий набір tools: setup може завантажити нові версії. Опис наявних компонентів і їх контрольні суми — `handoff/DEPENDENCY_INVENTORY.json`; це знімок, а не автоматичний lock-файл для завантаження.

## Запуск

- `START.cmd` — звичайний LowTube.
- `BENCHMARK.cmd` — основний автоматичний бенчмарк форматів/налаштувань.
- `HYBRID_EXPERIMENT.cmd` — один експериментальний режим.
- `HYBRID_BENCHMARK.cmd` — порівняння десяти режимів, опис у `hybrid/README.uk.md`.

Дані користувача зберігаються поза проєктом, у `%LOCALAPPDATA%\LowTube`. Цей каталог не вкладено в архів. Cookies, сесії браузера, історія й OAuth-конфігурація не переносилися.

## Перевірений стан

Перевірки цього перенесення записані в `handoff/TRANSFER_VALIDATION.md`. Запуск GUI, аудіо та D3D11VA на Windows у середовищі підготовки не перевірявся. Попередній тест 0.4 завершений; результатів деталізованого тесту 0.5 користувач ще не надав.

Не підміняйте висновок про поточний повільний прототип висновком про неможливість змішаного декодування загалом. Не впроваджуйте його в основний плеєр як рекомендований режим до вимірювань.

Для необов'язкових Python-тестів: `python -m pip install -r requirements-dev.txt`.
Перевірки експерименту з використанням встановленого .NET SDK 8: `python hybrid/test_queue.py "C:/Program Files/dotnet"` і `python hybrid/test_compare.py "C:/Program Files/dotnet"`.
Без Lupa Run-Checks.ps1 явно пропустить Lua-перевірку. Встановлення Python-пакетів не потрібне для запуску самого LowTube.
