LowTube 0.10.0 — відновлення перегляду, черги та стан плеєра

ВСТАНОВЛЕННЯ
1. Дочекайся завершення поточного бенчмарку. Закрий тестер і LowTube.
2. Відкрий папку LowTube всередині архіву та скопіюй її вміст у свою
   папку LowTube, погодившись на заміну файлів.
3. Запусти START.cmd. Повторний SETUP не потрібен.
Це патч для збірки 0.9.1. Компоненти tools, налаштування, сесії браузера,
еквалайзер та файли бенчмарку не замінюються.

ЩО ДОДАНО І ДЕ ШУКАТИ
• Відновлення останньої позиції увімкнене типово. Перемикач:
  Settings → Resume from last position. Після відкриття відео LowTube
  продовжує його автоматично; кнопка Start over запускає з початку.
  Позиції зберігаються раз на 5 с та перед зупинкою/закриттям.
  Для прямих трансляцій відновлення вимкнене. Завершені відео і відео
  з кількома останніми секундами починаються заново.
• Downloads у лівому меню: список завдань, поточний прогрес yt-dlp,
  помилка, папка, Cancel, Retry / resume, Resume pending, Remove.
  Вибір формату залишився у старому вікні Download. Після підтвердження
  завдання потрапляє в менеджер. Одночасно працює одне завантаження,
  інтерфейсом можна користуватись. Помилка одного не зупиняє інші.
  Після перезапуску перервані завдання чекають ручного відновлення.
  Часткові файли зберігаються. yt-dlp намагається їх дозавантажити;
  конвертація/об’єднання та деякі типи потоків можуть початися заново.
  Прогрес відео й аудіодоріжки показується окремими етапами, тому
  відсоток може початися з нуля для наступної доріжки.
• Watch queue у лівому меню. Add to queue додає вибране відео або
  плейлист. Є Play selected, Move up/down, Remove, Clear queue,
  Automatically play next. Next in queue — у головному вікні.
  Черга зберігається після виходу; Stop не очищає її.
  Поточне відео знаходиться в Local history, наступні — у Watch queue.
• Кнопка Video / Audio only на вибраному плейлисті запускає його
  через чергу. Browse playlist дозволяє просто відкрити список.
  Плейлист завантажується сторінками по 50 записів під час переходів;
  для початку з уже відкритої сторінки зберігається її розмір.
  Не створюються запити на всі відео великого плейлиста наперед.
  Недоступні записи залишаються в черзі з помилкою. Після трьох
  невдалих запусків за один перехід черга чекає ручної дії.
  Для повтору вибери запис і натисни Play selected.
• Помилки основних запитів показуються без спливаючих MessageBox:
  у правій частині нижнього рядка. Натискання відкриває подробиці
  та журнал. Стани списків і завантажень не стирають цю інформацію.
• Playback status у лівому меню: пауза/буферизація/перемотування,
  позиція, розмір кадру, кодеки, фактичний декодер, відеовихід,
  FPS джерела й оцінка FPS, пропуски кадрів, A/V розбіжність,
  наповнення буфера та швидкість. Є Copy і Player diagnostics.
  Відсутні показники позначені —. Це показники mpv, а не вимір
  реально показаних монітором кадрів. Нових процесів yt-dlp для
  цього екрана не запускається.
• F4 / права кнопка → Always on top і Keep above borderless
  fullscreen apps. Другий пункт періодично поновлює верхній шар
  без переведення фокуса на плеєр. Працює також для аудіовікна.
  Показ над ексклюзивним повноекранним режимом гри, захищеним
  робочим столом/UAC та іншими спеціальними поверхнями Windows
  не гарантується. Для гри використовуй режим без рамки.

ДАНІ
%LOCALAPPDATA%\LowTube\resume.json — позиції, до 1000 відео.
%LOCALAPPDATA%\LowTube\watch-queue.json — до 5000 записів черги.
%LOCALAPPDATA%\LowTube\downloads.json — до 1000 завдань менеджера.
У файлах черг є назви та посилання на відео, але немає копії cookies
або параметрів входу. Старі завдання можна видаляти з менеджера;
видалення запису менеджера не видаляє завантажений файл.

ПЕРЕВІРКИ
• Скомпільовано як Windows x64 / .NET Framework 4.8, C# 5.
• 283 наявні перевірки ядра; 25 нових перевірок відновлення, черги,
  сторінок плейлистів, послідовності/помилок/скасування завантажень.
• 35 перевірок Lua: перемотування, меню, діагностика й позиції.
• 456 записів локалізації EN/UK/RU, перевірені заповнювачі.
Тести логіки виконані на .NET 8; виконуваний файл зібрано проти
еталонних бібліотек .NET Framework 4.8. У цьому середовищі немає
Windows GUI та mpv, тому показ вікон, реальні апаратні режими,
мережеве відтворення і завантаження треба перевірити на ПК.
Нові перевірки можна запустити через tests\RUN_FEATURE_TESTS.cmd.
