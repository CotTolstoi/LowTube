LowTube 0.11.1 — виправлення сумісності з бенчмарком

Причина: у патчі 0.11.0 метод Backend.Resolve отримав новий параметр. Уже скомпільований LowTube.Benchmark.exe 1.2 викликає стару п’ятиаргументну версію й завершувався повідомленням «Метод не найден».

Виправлення: старий метод збережено з тим самим двійковим підписом. Він передає виклик новій реалізації. Оновлення формату та інші можливості 0.11.0 збережені. Файлова версія LowTube.exe — 0.11.1; версія збірки 0.11.0 залишається для сумісності.

Встановлення:
1. Закрий LowTube і тестер.
2. Розпакуй папку LowTube з цього архіву поверх наявної LowTube 0.11.0 та заміни файли.
3. Запусти той самий BENCHMARK.cmd. Перезбирання бенчмарку не потрібне.

Патч містить LowTube.exe та лише два змінені файли коду. Зовнішні пакети та файли бенчмарку не змінюються.

Перевірка: Windows x64 EXE скомпільовано для .NET Framework 4.8; вихідний код бенчмарку 1.2 скомпільовано з новим LowTube.exe; 283 базові й 26 тестів нових функцій виконано. Реальний запуск на Windows треба перевірити на ПК користувача.
