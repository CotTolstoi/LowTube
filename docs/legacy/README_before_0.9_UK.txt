LowTube 0.7.0 — повна збірка Windows 10/11 x64

Розпакуй у нову папку та запусти START.cmd. Node.js 22 (стандартний),
yt-dlp, mpv, FFmpeg/ffprobe, QuickJS-NG, Deno та QuickJS classic включені.
Не запускай EXE всередині ZIP. Потрібна .NET Framework 4.8.
Налаштування/локальна історія/сесія з попередньої версії беруться з
%LOCALAPPDATA%\LowTube на цьому самому Windows-акаунті. Чужих сесій в архіві немає.
SETUP.cmd потрібний для перевстановлення/оновлення компонентів, не першого
завантаження включених файлів. Він тепер встановлює Node22 і зберігає інші JS-рушії.

НОВЕ
• F4 / права кнопка → Video settings: auto, auto-copy, dxva2, dxva2-copy,
  d3d11va, d3d11va-copy, nvdec, nvdec-copy, no. Показано Active decoder.
  dxva2/d3d11va автоматично вибирають D3D11; nvdec вибирає OpenGL.
  Зміна рендерера може перезапустити mpv, зберігаючи позицію та гучність.
  Copy-режими зберігають твій вибір рендерера. Наявний декодер збережено;
  для нового користувача стандартний режим — auto.
• Settings → Recommendations language: окрема мова від мови інтерфейсу.
  Вибір впливає на пошуковий запит та youtube:lang; це мовна перевага,
  а не гарантований фільтр озвучення. Для точніших результатів також
  напиши тему обраною мовою. Підписки та звичайний пошук не змінені.
• Download → Download resolution: All, 720p, 1080p, 1440p, 2160p (4K).
  1440p/4K вибирають MKV та прибирають ліміти H.264/30 FPS для завантаження.
  Можна потім самостійно змінити формат і обмеження. MP4 також дозволяє
  доступні MP4-потоки AV1, якщо вимкнути H.264 only. Параметри перегляду
  не змінюються. Завантажується обраний ID у рідному розмірі, без збільшення
  чи перекодування. Якщо відео не має 4K, програма не створює штучний 4K.
  Ультраширокі потоки групуються за позначкою джерела/шириною, фактичний
  розмір завжди видно в списку. Якість 1440p у меню означає QHD, не DCI 2K.

СУМІСНІСТЬ
Ця збірка — тільки x64. Lenovo S12 з Atom N270/945GSE (GMA950) є 32-бітним
і не запустить її. Для нього потрібна окрема x86-версія та інші залежності;
повноцінного H.264-декодера в GMA950 немає. Сучасні 64-бітні Atom з іншою
графікою можуть використовувати D3D11VA, якщо драйвер підтримує цей кодек.
Докладна таблиця режимів і джерела: HARDWARE_MODES.md.

ДІАГНОСТИКА
START_PLAYBACK_DEBUG.cmd → проблемне відео → F8 під час фрізу → закрий LowTube.
Надішли playback-debug.txt і startup.txt із %LOCALAPPDATA%\LowTube.
Підтримка конкретного GPU/кодека підтверджується Active decoder та журналом,
а не лише обраним пунктом. Після невдалого hwdec mpv може перейти на CPU.

2. Розпакуй архів у наявну папку із заміною файлів. Залиш папку tools
   з mpv, yt-dlp, FFmpeg і QuickJS на місці.
3. Запусти LowTube.exe або START.cmd. У заголовку буде версія 0.6.

інсталяції або оновлення всіх компонентів. Збережи нову папку player
зі скриптом lowtube.lua: не копіюй лише EXE. Налаштування, сесія браузера,
історія та обраний буфер зберігаються у %LOCALAPPDATA%\LowTube.

ПЕРШЕ ВСТАНОВЛЕННЯ
Розпакуй увесь архів у папку, доступну для запису, і запусти SETUP.cmd.
Потрібні Windows x64, .NET Framework 4.8 та інтернет. Після завершення

Самі LowTube і портативні компоненти не потребують адміністратора.
Інструкції щодо старих помилок інсталятора — в кінці цього файла.

Доступні English, Українська і Русский. Типова мова першого запуску — English.

Вибір запам'ятовується. Перекладено елементи

ПОШУК І ВІДЕО
Введи запит або URL YouTube й натисни «Пошук / URL». Списки містять
до 25 результатів на сторінці, пошук — до 100. Обери рядок і натисни
«Відео» або двічі клацни його. Якщо рядок виділений, дії стосуються його.
Для іншого посилання виконай новий пошук / URL.

Відео відкривається у звичайному вікні mpv. Space — пауза, F — весь
екран, стрілки — перемотування, I / Shift+I — статистика, Q — закрити.
Керування паузою, перемотуванням і зупинкою доступне також у LowTube.
Межа висоти та H.264 / 30 FPS у головному вікні стосуються ПЕРЕГЛЯДУ.
Якщо 720p доступне лише при 60 FPS, обмеження до 30 FPS може вибрати
480p. Зніми цей ліміт для проби вищої якості, враховуючи навантаження.

ЛИШЕ АУДІО
Кнопка «Лише аудіо» запускає невелике вікно з прев'ю, назвою, каналом,
позицією, гучністю, паузою та перемотуванням. Велике вікно mpv не
створюється. Завантажується лише аудіопотік і одна JPEG-мініатюра,
без відеопотоку, WebView чи декодування відео.
Закриття компактного вікна або «Стоп» зупиняє звук. Згортання — ні.
Якщо мініатюра недоступна, з'явиться текстова заглушка; звук працює далі.
Після природного завершення вікно лишається з позначкою завершення.
Для повтору знову натисни «Лише аудіо» в головному вікні.

ЗАВАНТАЖЕННЯ
1. Обери відео й натисни «Скачати». Клієнт отримає список потоків.
2. В окремому вікні обери «Відео зі звуком» або «Лише аудіо».
3. Для відео обери MP4, MKV або WebM, потім конкретний розмір / FPS /
   кодек. У списку також є позначка джерела та ID потоку.
   Для аудіо обери M4A, MP3 або Opus і доступний аудіопотік.
4. Для MP3 додатково обери бітрейт 96–320 кбіт/с. Вищий бітрейт не
   відновлює втрати джерела. MP3-конвертація навантажує процесор.
5. Натисни «Скачати». Перебіг видно у головному журналі; «Скасувати»
   зупиняє завантаження. Закриття діалогу до підтвердження нічого не качає.

MP4 — H.264 + AAC; WebM — доступні WebM-кодеки; MKV — обраний кодек.
Для MKV є власна позначка H.264. Ліміт до 30 FPS у діалозі незалежний
від перегляду й типово вимкнений. Налаштування діалогу запам'ятовуються
після підтвердження. Якість перегляду при цьому не змінюється.
M4A та Opus зберігаються без перекодування; MP3 — з перекодуванням аудіо.
У режимі «Лише аудіо» відсутні відеопотоки, навіть для конвертації MP3.

Список містить фактичні розміри доступних потоків. Наприклад, 1536×640
збережеться саме 1536×640. Клієнт не масштабує і не розтягує відео.
Якщо обраний потік зник, буде помилка, а не прихована заміна на нижчу якість.
Файли різних потоків та різних бітрейтів MP3 отримують різні назви.
Готові файли не перезаписуються. Повтор того самого вибору може продовжити
.part. Старі .part з інших версій / назв автоматично не підхоплюються.
Папку можна обрати в «Параметри»; кнопка «Папка» відкриває її.
Зберігай відео, які маєш право завантажувати.

БУФЕР, ДЕКОДЕРИ ТА ДІАГНОСТИКА
F4 або права кнопка миші У ВІКНІ mpv відкриває параметри відео:
максимальну якість, FPS, H.264, декодер, вивід, швидкість і буфер.
«Застосувати» змінює потік у тому самому процесі mpv з поточної позиції, зберігаючи паузу
й гучність. «Скасувати» не змінює відтворення. Це ж вікно доступне
через «Параметри відео» у LowTube. Для паузи використовуй пробіл або
кнопку плеєра — права кнопка миші тепер відкриває параметри.

У параметрах LowTube та плеєра є числові поля:
- Буфер уперед: 5–3600 секунд.
- Пам’ять уперед: 16–1024 MiB на демультиплексор.
- Буфер назад: 0–512 MiB на демультиплексор.
- Поріг старту / поповнення: 1–30 секунд, не вище тривалості буфера.
Попередні значення 12/60/120 секунд зберігають межі 32/64/128 MiB.
Відео й окреме аудіо мають власні буфери; їхня пам’ять додається.
Наприклад, 128 MiB уперед + 16 MiB назад — приблизно до 288 MiB на два
потоки, плюс пам’ять декодера, виводу й програми. Межа пам’яті може
зупинити накопичення раніше заданої кількості секунд.
Буфер 300 секунд з порогом 2 секунди НЕ чекає п’ять хвилин перед стартом.
Медіакеш залишається в оперативній пам’яті, запис на HDD вимкнений.
У Settings зміни діють при наступному запуску; F4 > «Застосувати»
перезапускає поточне відео з новими значеннями.

Захист перемотування призупиняє звук до повідомлення mpv про готовність
відео. Працює для шкали часу, клавіатури й кнопок LowTube. Якщо паузу
ввімкнув ти, вона зберігається. Після 30 секунд очікування плеєр лишається
на паузі й показує повідомлення: можна натиснути пробіл або обрати іншу
позицію. Режим вимикається в параметрах F4. mpv синхронізується зі звуком.
Це усуває випередження під час очікування відео, але не гарантує виправлення
всіх помилок старого драйвера GPU. Якщо відставання лишиться, зніми
«Діагностику плеєра» ПІД ЧАС проблеми й спробуй програмний декодер no
або F4 > «Застосувати», щоб перезапустити декодер з поточної позиції.

ЗАПУСК З HDD І ВИМІРЮВАННЯ
Для JSON більше не завантажується System.Web. Історія й перевірка
компонентів читаються після появи вікна; запуск процесів не блокує UI.
Розпакований yt-dlp не розпаковує свій runtime при кожному запуску.
Дані вибраних потоків кешуються лише в RAM: до 3 хвилин, 4 записи.
Повторний запуск або зміна лише буфера/декодера використовує кеш.
Інша якість чи сесія має окремий запис. «Очистити кеш потоків» у параметрах
змушує отримати свіжі дані, якщо збережене посилання не працює.
Settings > Startup report / Параметри > Звіт запуску показує етапи:
запуск процесу та CLR, побудову й малювання вікна, читання історії,
отримання потоків, запуск mpv і спостережувану готовність відтворення.
Копія: %LOCALAPPDATA%\LowTube\startup.txt. Cookies і URL потоків не записуються.
Точного прискорення у секундах без тесту на твоєму HDD не обіцяємо.

DXVA2, D3D11VA, автоматичний і програмний режими обираються вручну;
вивід — D3D11 або OpenGL. Наявність режиму не гарантує прискорення
на конкретному драйвері. Старе обладнання не отримує нових апаратних кодеків.
«Діагностика плеєра» показує два виміри: hwdec-current = no означає
програмне декодування; paused-for-cache = true — очікування даних.
Порівнюй лічильники пропущених кадрів і запас буфера під час проблеми.
Звіт можна скопіювати. Перевірка працює також для аудіо; відеополя
в цьому режимі можуть бути недоступні.

«Рекомендації» показують відкритий пошук YouTube за темою. Зміни «Тема
гостьових рекомендацій» у параметрах; типово — science and technology.
Це добірка за темою, а не персональна головна сторінка Google.
Вибери відео й натисни «Підписатися локально», щоб додати його канал.
У «Канали» можна додати URL каналу / @handle або видалити підписку.
«Підписки» оновлюють останні відкриті відео, починаючи з найновіших.
«Далі 25» гортає завантажений список. Якщо каналів немає, відкриється
вікно їх додавання. Підписки зберігаються на ПК без синхронізації з Google.
До 100 каналів, два одночасні запити, оновлення лише після натискання.
Відкрита стрічка зазвичай містить 15 останніх публікацій, а не весь архів.
Якщо канал недоступний, показується кеш із повідомленням у журналі.
Рекомендації й локальні підписки не читають cookies, навіть якщо сесію
ввімкнено для пошуку, перегляду та скачування.
Файли: %LOCALAPPDATA%\LowTube\subscriptions.json і кеш у feeds\.

АКАУНТ
Увійди в YouTube у звичайному Firefox, відкрий «Акаунт» і обери сесію
Firefox. Порожній шлях означає типовий профіль. Для іншого профілю
скопіюй «Кореневий каталог» з about:profiles. Якщо база зайнята —
закрий Firefox і повтори. cookies.sqlite не є cookies.txt.
Альтернатива — власний файл Netscape cookies.txt. Пароль вводиться
тільки на сайті Google. Cookies використовуються локально, не надсилай їх.
За замовчуванням сесія діє лише для історії YouTube. Для пошуку,
перегляду й скачування є окрема позначка в налаштуваннях акаунта.
Читання історії YouTube експериментальне. Клієнт не записує перегляди
в історію Google і не керує підписками твого Google-акаунта.
Локальна історія зберігає останні 500 запусків. Немає OAuth-входу чи сервера LowTube.

ОНОВЛЕННЯ КОМПОНЕНТІВ І ПОМИЛКИ
Для оновлення компонентів закрий клієнт і запусти SETUP.cmd. Перевірені
архіви залишаються у download-cache і повторно використовуються після SHA256.
Після успіху цю папку можна видалити, щоб звільнити місце.
403 / HTTP 429 / bot check / PO Token — можливі обмеження YouTube;
онови компоненти та за потреби підключи власну сесію. Обходу DRM тут немає.
Не надсилай cookies або профіль браузера для діагностики.

Старі помилки інсталятора:
- ffprobe: використовується повний FFmpeg win64 GPL shared від yt-dlp,
  із ffprobe.exe та всіма DLL. Не використовуй урізану збірку без ffprobe.
- mpv -1073741515 / 0xC0000135: Windows не змогла завантажити DLL.
  Поточна збірка mpv потребує vulkan-1.dll навіть для D3D11-виводу.
  SETUP перевіряє x64 loader і може додати перевірений офіційний runtime
  поряд із mpv. Якщо завантаження заблоковано, відкрий
  https://vulkan.lunarg.com/sdk/home#windows і встанови Runtime Installer
  для Windows x64/x86 (не SDK). Цей системний інсталятор може потребувати
  адміністратора. Або поклади офіційний
  VulkanRT-X64-1.4.363.0-Components.zip поряд із SETUP.cmd і повтори.
  Loader не додає апаратну підтримку Vulkan у стару відеокарту.
  Якщо помилка лишається, дивись setup-diagnostics.txt: причина може бути іншою.
- Illegal instruction / 0xC000001D: перевір сумісність компонента з CPU.
  older dual-core CPU не підходять збірки x86_64-v3 / AVX2.

РОЗРОБКА ТА ОБМЕЖЕННЯ
BUILD.cmd збирає всі src/*.cs вбудованим компілятором .NET Framework.
I18n.cs містить переклади; AudioForm.cs — компактний плеєр;
DownloadForm.cs — діалог якості. tests/RUN_TESTS.cmd перевіряє логіку.
Джерела компонентів — SOURCES.md; фактичні перевірки — VALIDATION.txt.
WinForms без вбудованого браузера, телеметрії та автоматичного
оновлення компонентів у фоні. Спонсорські інтеграції у відео не вирізаються.
Клієнт неофіційний; майбутні зміни YouTube можуть порушити його роботу.

Для вимірювання запускай START.cmd: він також фіксує час до створення процесу.
