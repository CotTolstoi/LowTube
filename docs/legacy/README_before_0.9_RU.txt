LowTube 0.7.0 — полная сборка Windows 10/11 x64

Распакуй в новую папку и запусти START.cmd. Включены Node.js 22 (стандартный),
yt-dlp, mpv, FFmpeg/ffprobe, QuickJS-NG, Deno и классический QuickJS.
Нужна .NET Framework 4.8. Настройки/история/сессия берутся из
%LOCALAPPDATA%\LowTube текущего пользователя Windows. Чужих сессий в архиве нет.
SETUP.cmd обновляет компоненты, устанавливает Node22 и сохраняет другие JS-движки.

F4 / правая кнопка → Video settings: auto, auto-copy, dxva2, dxva2-copy,
d3d11va, d3d11va-copy, nvdec, nvdec-copy, no. Видно фактически активный декодер.
Прямые DXVA2/D3D11VA выбирают D3D11; NVDEC выбирает OpenGL. При смене рендерера
mpv может перезапуститься с сохранением позиции. Текущие настройки сохраняются;
для новых пользователей стандартный режим — auto. Подробнее: HARDWARE_MODES.md.
Settings → Recommendations language: язык тематического поиска отдельно от
интерфейса. Это предпочтение поиска, не строгий фильтр языка озвучки.
Download → Download resolution: добавлены 1440p и 2160p (4K). Эти наборы выбирают
MKV и снимают ограничения кодека/FPS скачивания. Без увеличения разрешения и
перекодирования. MP4 допускает доступные потоки AV1 MP4 при выключенном H.264 only.
Параметры просмотра независимы. 1440p означает QHD, а не DCI 2K.
START_PLAYBACK_DEBUG.cmd включает диагностику; F8 отмечает проблему.

Эта x64-сборка не запускается на Lenovo S12 с 32-битным Atom N270/GMA950.
Нужна отдельная x86-версия с другими зависимостями; GMA950 не имеет полноценного
аппаратного H.264-декодера. Более новые x64 Atom зависят от кодека и драйвера.

LOWTUBE 0.6 — WINDOWS 10/11 x64

НОВОЕ В 0.6

  Новый поток требует буферизации. Смена рендерера может перезапустить mpv.

  до 4 видео на 3 минуты. Прямые эфиры не кешируются. Лимит исходного JSON:
  8 MiB всего, 4 MiB на видео; фактическое использование RAM больше.
  Настройки > Очистить кэш потоков — повторно получить форматы.
- Отдельная сессия: Аккаунт > Настройки Firefox / cookies > Сохранить сессию
  Firefox или Импортировать сохранённую сессию, затем Сохранить. После импорта
  автоматически выбираются сохранённая сессия и её использование для видео.
  Firefox нужен только для копирования/обновления сессии, не каждого запуска.
  Если сессия недействительна, скопируй её заново. Фиксированного срока нет;
  сохранённая сессия не гарантирует отсутствие проверки «вы не бот».
- Копия содержит только cookies YouTube и зашифрована Windows DPAPI для
  текущего пользователя Windows. Пока работает yt-dlp, существует приватный
  временный файл. Он удаляется после завершения; следующее использование
  сессии очищает остатки после сбоя. Удалить сохранённую сессию удаляет копию.
  Режимы Firefox/файл, Google OAuth и остальные функции сохранены.

Сохрани новую папку player с lowtube.lua: не копируй только EXE.
Настройки, пути сессии браузера, выбранный буфер и история сохраняются
в %LOCALAPPDATA%\LowTube.

ПЕРВАЯ УСТАНОВКА
Распакуй весь архив в папку, доступную для записи, и запусти SETUP.cmd.
Нужны Windows x64, .NET Framework 4.8 и интернет. Visual Studio, Python
и Node.js не нужны. Установщик проверяет SHA256 компонентов и выбирает
обычные x86_64-сборки, а не x86_64-v3. LowTube и портативные компоненты
не требуют администратора. Решения старых ошибок установки — ниже.

ЯЗЫК
Открой Settings / Настройки > Language / Язык, выбери язык и Save / Сохранить.
Доступны English, Українська и Русский. При первом запуске язык — English.
Ранее выбранный язык сохраняется. Здесь же есть Theme / Тема: Light / Светлая
или Dark / Тёмная. После сохранения открытые окна LowTube изменятся сразу.
Системные диалоги, полосы прокрутки Windows и mpv имеют своё оформление.
Выбор запоминается. Переведены элементы LowTube,
сообщения, настройки, аккаунт, скачивание и компактный аудиоплеер.
Названия видео и каналов не переводятся. Технические журналы yt-dlp,
mpv, FFmpeg, названия кодеков и системные диалоги Windows имеют свой язык.
Кнопка профиля legacy test laptop удалена. Текущие настройки просмотра сохранены.
При первой установке остаются осторожные значения: H.264, до 30 FPS,
720 px, dxva2-copy, d3d11. Кнопки сброса на профиль устройства больше нет.

ПОИСК И ВИДЕО
Введи запрос или ссылку YouTube и нажми «Поиск / URL». Выбери строку
и нажми «Видео» либо дважды щёлкни по ней. В списке до 25 результатов
на странице, поиск охватывает до 100. Выделенная строка имеет приоритет
над полем поиска; для другого URL выполни новый поиск / URL.

Видео открывается в обычном окне mpv. Space — пауза, F — полный экран,
стрелки — перемотка, I / Shift+I — статистика, Q — закрыть окно.
Пауза, перемотка и остановка доступны также в LowTube.
Лимиты высоты, H.264 и FPS в главном окне относятся к ПРОСМОТРУ.
Если 720p доступно только при 60 FPS, ограничение до 30 FPS может выбрать
480p. Сними лимит для пробы высокого качества, учитывая нагрузку на ПК.

ТОЛЬКО АУДИО
Кнопка «Только аудио» открывает небольшое окно с превью, названием,
каналом, позицией, громкостью, паузой и перемоткой. Большое окно mpv
не создаётся. Загружается только аудиопоток и одна JPEG-миниатюра:
без видеопотока, декодирования видео и встроенного браузера.
Закрытие компактного окна или «Стоп» останавливает звук; сворачивание — нет.
Если превью недоступно, появляется текстовая заглушка, а звук продолжает
работать. После окончания окно остаётся с отметкой завершения.
Для повтора снова нажми «Только аудио» в главном окне.

СКАЧИВАНИЕ
1. Выбери видео и нажми «Скачать». Дождись списка доступных потоков.
2. В отдельном окне выбери «Видео со звуком» или «Только аудио».
3. Для видео выбери MP4, MKV или WebM, затем фактический размер / FPS /
   кодек. Также показаны метка источника и ID потока.
   Для аудио выбери M4A, MP3 или Opus и доступный аудиопоток.
4. Для MP3 дополнительно выбери битрейт 96–320 кбит/с. Больший битрейт
   не восстанавливает потери источника. Конвертация в MP3 нагружает CPU.
5. Нажми «Скачать». Ход работы виден в главном журнале; «Отмена»
   останавливает загрузку. Закрытие диалога до подтверждения не скачивает медиа.

MP4 — H.264 + AAC; WebM — доступные WebM-кодеки; MKV — выбранный кодек.
Для MKV есть отдельный переключатель H.264. Лимит 30 FPS в диалоге
независим от просмотра и по умолчанию выключен. Выбор запоминается
после подтверждения; качество просмотра при этом не меняется.
M4A и Opus сохраняются без перекодирования, MP3 — с конвертацией аудио.
В режиме «Только аудио» видеопотоки не скачиваются, даже для MP3.

Выбранные размеры источника сохраняются. Например, 1536×640 останется
1536×640: без увеличения и растягивания. Если выбранный поток исчезнет,
появится ошибка вместо скрытого перехода к более низкому качеству.
Разные ID потоков и битрейты MP3 получают разные имена файлов.
Готовые файлы не перезаписываются. Повтор того же выбора может продолжить
.part. Старые .part с другими именами автоматически не подхватываются.
Папку можно выбрать в «Настройки»; кнопка «Папка» открывает её.
Сохраняй медиа, которые имеешь право скачивать.

БУФЕР И ДИАГНОСТИКА
F4 или правая кнопка мыши В ОКНЕ mpv открывает настройки видео:
максимальное качество, FPS, H.264, декодер, вывод, скорость и буфер.
«Применить» меняет поток в том же процессе mpv с текущей позиции, сохраняя паузу
и громкость. «Отмена» не меняет воспроизведение. То же окно доступно
через «Настройки видео» в LowTube. Для паузы используй пробел или
кнопку плеера — правая кнопка мыши теперь открывает настройки.

В настройках LowTube и плеера есть числовые поля:
- Буфер вперёд: 5–3600 секунд.
- Память вперёд: 16–1024 MiB на демультиплексор.
- Буфер назад: 0–512 MiB на демультиплексор.
- Порог старта / пополнения: 1–30 секунд, не выше длительности буфера.
Прежние значения 12/60/120 секунд сохраняют лимиты 32/64/128 MiB.
Видео и отдельное аудио имеют свои буферы; их память складывается.
Например, 128 MiB вперёд + 16 MiB назад — примерно до 288 MiB для двух
потоков, плюс память декодера, вывода и программы. Лимит памяти может
остановить накопление раньше заданного количества секунд.
Буфер 300 секунд с порогом 2 секунды НЕ ждёт пять минут перед стартом.
Медиакэш остаётся в RAM, запись на HDD отключена.
В Settings изменения действуют при следующем запуске; F4 > «Применить»
перезапускает текущее видео с новыми значениями.

Защита перемотки приостанавливает звук до сообщения mpv о готовности
видео. Работает со шкалой времени, клавиатурой и кнопками LowTube.
Если паузу включил ты, она сохраняется. Через 30 секунд ожидания плеер
остаётся на паузе и показывает сообщение: можно нажать пробел или выбрать
другую позицию. Режим отключается в настройках F4. mpv синхронизируется
со звуком. Это предотвращает опережение во время ожидания видео, но не
гарантирует исправление всех ошибок старого GPU-драйвера. Если отставание
останется, сними «Диагностику плеера» ВО ВРЕМЯ проблемы и попробуй
программный декодер no или F4 > «Применить» для перезапуска декодера.

ЗАПУСК С HDD И ИЗМЕРЕНИЯ
Для JSON больше не загружается System.Web. История и проверка компонентов
читаются после появления окна; запуск процессов не блокирует UI.
Распакованный yt-dlp не распаковывает свой runtime при каждом запуске.
Данные выбранных потоков кэшируются только в RAM: до 3 минут, 4 записи.
Повторный запуск или изменение только буфера/декодера использует кэш.
Другое качество или сессия имеет отдельную запись. «Очистить кэш потоков»
в настройках запрашивает свежие данные, если сохранённая ссылка не работает.
Settings > Startup report / Настройки > Отчёт запуска показывает этапы:
запуск процесса и CLR, построение и отрисовку окна, чтение истории,
получение потоков, запуск mpv и наблюдаемую готовность воспроизведения.
Копия: %LOCALAPPDATA%\LowTube\startup.txt. Cookies и URL потоков не записываются.
Точное ускорение в секундах без теста на твоём HDD не обещаем.

Декодеры: DXVA2, D3D11VA, автоматический и программный режимы;
вывод — D3D11 или OpenGL. Выбор режима не доказывает работу ускорения.
Старое оборудование не получает новых аппаратных кодеков от настройки.
«Диагностика плеера» собирает два замера: hwdec-current = no означает
программное декодирование; paused-for-cache = true — ожидание данных.
Сравни счётчики пропусков кадров и запас буфера во время проблемы.
Отчёт можно скопировать. Для аудио диагностика тоже работает, но поля
видео могут быть недоступны.

БЕЗ АККАУНТА
«Рекомендации» показывают открытый поиск YouTube по теме. Измени «Тема
гостевых рекомендаций» в настройках; по умолчанию — science and technology.
Это подборка по теме, а не персональная главная страница Google.
Выбери видео и нажми «Подписаться локально», чтобы добавить его канал.
В «Каналы» можно добавить URL канала / @handle или удалить подписку.
«Подписки» обновляют последние открытые видео, начиная с самых новых.
«Следующие 25» листает загруженный список. Если каналов нет, откроется
окно их добавления. Подписки хранятся на ПК без синхронизации с Google.
До 100 каналов, два одновременных запроса, обновление только по нажатию.
Открытая лента обычно содержит 15 последних публикаций, а не весь архив.
Если канал недоступен, показывается кэш с сообщением в журнале.
Рекомендации и локальные подписки не читают cookies, даже если сессия
включена для поиска, просмотра и скачивания.
Файлы: %LOCALAPPDATA%\LowTube\subscriptions.json и кэш в feeds\.

АККАУНТ
Войди в YouTube в обычном окне Firefox. В «Аккаунт» выбери сессию Firefox.
Пустой путь означает профиль по умолчанию. Для другого профиля скопируй
«Корневой каталог» из about:profiles. Если база занята — закрой Firefox
и повтори запрос. cookies.sqlite не является файлом cookies.txt.
Альтернатива — собственный Netscape cookies.txt. Пароль вводится только
на сайте Google. Cookies используются локально; не передавай их другим.
По умолчанию сессия действует только для истории YouTube. Для поиска,
просмотра и скачивания есть отдельная галочка в настройках аккаунта.
Чтение истории YouTube экспериментальное. Клиент не записывает просмотры
в историю Google и не управляет подписками твоего Google-аккаунта.
Локальная история хранит последние 500 запусков. Нет встроенного OAuth
и сервера LowTube.

ОБНОВЛЕНИЕ КОМПОНЕНТОВ И ОШИБКИ
Для обновления компонентов закрой клиент и запусти SETUP.cmd.
Проверенные архивы остаются в download-cache; перед повторным использованием
их SHA256 проверяется снова. После успеха папку можно удалить для экономии места.
YouTube может возвращать 403, 429, bot check или требовать PO Token.
Обнови компоненты и при необходимости подключи собственную сессию.
Обход DRM не предусмотрен. Не отправляй cookies и профиль браузера для диагностики.

Старые ошибки установщика:
- ffprobe: нужен полный пакет yt-dlp FFmpeg win64 GPL shared с ffprobe.exe
  и всеми DLL. Урезанная сборка без ffprobe не подходит.
- mpv -1073741515 / 0xC0000135: Windows не смогла загрузить нужную DLL.
  Текущая сборка mpv импортирует vulkan-1.dll даже для D3D11-вывода.
  SETUP проверяет x64 loader и может добавить проверенный официальный
  runtime рядом с mpv. Если загрузка заблокирована, открой
  https://vulkan.lunarg.com/sdk/home#windows и установи Runtime Installer
  для Windows x64/x86 (не SDK). Этот системный установщик может потребовать
  администратора. Либо положи официальный
  VulkanRT-X64-1.4.363.0-Components.zip рядом с SETUP.cmd и повтори.
  Loader не добавляет аппаратную поддержку Vulkan старой видеокарте.
  Причина может быть в другой DLL; смотри setup-diagnostics.txt.
- Illegal instruction / 0xC000001D: проверь совместимость компонента с CPU.
  older dual-core CPU не подходят сборки x86_64-v3 / AVX2.

РАЗРАБОТКА И ОГРАНИЧЕНИЯ
BUILD.cmd компилирует все src/*.cs встроенным компилятором .NET Framework.
I18n.cs содержит переводы, AudioForm.cs — компактный плеер,
DownloadForm.cs — диалог качества. tests/RUN_TESTS.cmd проверяет логику.
Источники компонентов — SOURCES.md; выполненные проверки — VALIDATION.txt.
Нативный WinForms без встроенного браузера, телеметрии и фонового
обновления компонентов. Спонсорские вставки внутри видео не вырезаются.
Клиент неофициальный; будущие изменения YouTube могут нарушить его работу.

Для измерения запускай START.cmd: он также фиксирует время до создания процесса.
