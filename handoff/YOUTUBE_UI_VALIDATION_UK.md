# Інтерфейс у стилі YouTube — 0.12.0

## Що змінено

Верхня панель із пошуком/URL, кнопкою облікового запису та власним логотипом LowTube. Ліва панель має намальовані іконки, виділення поточного розділу, підказки та згортання до вузької смуги. Контент-фільтри представлені кнопками All content / Videos / Shorts / Live streams / Playlists; вони керують тим самим ComboBox-моделем фільтра, тому чинна логіка пошуку/каналів збережена.

Сітка використовує округлені прев'ю, бейдж тривалості/типу, індикатор перегляду, ініціали каналу, два рядки назви, метадані й три крапки для існуючого меню дій. Один клік по прев'ю запускає відео; подвійний клік по прев'ю не дублює запуск. Заголовок можна виділити для інших дій або активувати подвійним кліком; навігація стрілками та Enter збережена. Правий клік і три крапки відкривають те саме меню.

Налаштування висоти/FPS/кодека/декодера/рендера та Available formats / Player diagnostics доступні через Playback options. Журнал продовжує збиратися з попереднім лімітом і відкривається через Details. Початково обидві секції згорнуті. Список, сторінки, канали, підписки, історія, синхронізація, плейлисти, черга, завантаження, каталог файлів, еквалайзер, налаштування, сесія, audio-only, керування mpv та pin збережені. Вузькі панелі дій мають штатне прокручування Windows, щоб усі кнопки залишалися доступними.

Застосунок лишається WinForms C# 5 / .NET Framework 4.8. Використовуються GDI+ та штатні контролі. Немає WebView, Electron, додаткових бібліотек, анімацій або мережевих аватарів. Попередні межі кешу прев'ю (64 зображення 320x180, дві паралельні операції, 512 КіБ на відповідь) збережені. Зростання/зменшення швидкодії не вимірювалися й не заявляються.

Темна й світла теми та англійська/українська/російська мови збережені, стандартна мова — English. Існуючі налаштування користувача не скидаються. Backend, InnerTube/yt-dlp, вибір форматів, відновлення потоку й hybrid-архітектура не змінені.

Підказка порожнього пошуку використовує штатний [EM_SETCUEBANNER](https://learn.microsoft.com/en-us/windows/win32/controls/em-setcuebanner), без накладеного поверх редактора Label; поле залишається доступним з клавіатури й оновлює підказку при зміні мови.

## Перевірки

Усі чотири власні EXE зібрано разом через Build-All.ps1. AssemblyFileVersion 0.12.0.0; AssemblyVersion лишився 0.11.0.0.

`Run-Checks.ps1 -WindowsMedia -WindowsUi`:

- 515 попередніх перевірок C# (Core/Feature/Google/Continuity/InnerTube/Reliability/StreamOpen/PlaybackSelection/BenchPlan).
- 173 перевірки справжніх WinForms-контролів: 12 поєднань розміру 1280×840 / 980×680, теми й мови; межі рядків пошуку/заголовка, підказка пошуку, 15 дій навігації, розмір відеообласті, згортання/повернення sidebar, доступність options/log, вибір фільтра й перенесення виділення між картками та списком. Перевірені одинарне/подвійне натискання прев'ю, меню та клавіатурний запуск.
- 23 попередні native mpv-перевірки відкриття, Stop/OSC/quit/переходу й IPC.
- 509 повних записів локалізації, 412 використаних ключів.
- Необов'язковий Lua sampler через Lupa пропущено через відсутню залежність. Native mpv-тести виконують встановлений Lua mpv.

WinForms-тест викликає приватний MainForm(bool preview), який пропускає читання settings/history/resume/queue/download/library, фон feed/mpv, таймери та startup-запис. Звичайний публічний конструктор не змінює контракт. Вікно тесту розміщене поза екраном, прев'ю й назви синтетичні, завантаження картинок заборонене. Створені знімки DrawToBitmap у handoff/previews/ візуально перевірені; під час перевірки виправлено обрізання вкладених TableLayoutPanel та підказки пошуку.

Це компіляція, офлайн-логіка, реальний WinForms/GDI та Windows mpv IPC із null audio/video. Фізичне масштабування DPI на різних моніторах, доступність через screen reader, відеовивід/аудіопристрій, старий GPU та плавність на ASUS X71SL залишаються окремою перевіркою. Бенчмарки та запити YouTube не запускалися; tools і налаштування користувача не оновлювалися.
