# LowTube для Linux — початковий перенос

Ця збірка починає нативний Linux-порт окремо від Windows-версії. Поточний зріз містить пошук, публічні підписки, локальні «Збережене» й історію, завантаження через `yt-dlp`, а також окреме вікно `mpv` з керуванням і перемотуванням через Unix socket. Є базові параметри якості, FPS, кодека, кешу та каталогу завантажень. Решта функцій ще переноситься.

## Потрібно

- .NET SDK 8;
- `yt-dlp` і `mpv` у `PATH`;
- системні графічні бібліотеки, які потрібні Avalonia/Skia на вибраному дистрибутиві.

Після встановлення потрібних пакетів зберіть і запустіть застосунок:

```sh
cd linux/LowTube.Linux
dotnet run
```

Застосунок використовує системні `yt-dlp` та `mpv`, не завантажує їх автоматично й не передає пошуковий текст через shell. Налаштування зберігаються у `$XDG_CONFIG_HOME/lowtube/settings.json`, локальна бібліотека — у `$XDG_DATA_HOME/lowtube/library.json` (відповідно `~/.config` та `~/.local/share`, якщо XDG-змінні не задані). Файли приватні для поточного користувача.

## Межі поточного етапу

`mpv` відкривається окремим вікном. UI може ставити відтворення на паузу, зупиняти, перемотувати й змінювати гучність. Черга, відновлення позиції, еквалайзер і вбудоване відео ще не перенесені. Пошук і завантаження поки не використовують збережену сесію; канали мають бути публічними. `--hwdec=auto-safe` дозволяє mpv обрати безпечний доступний режим, але сам параметр не є доказом апаратного декодування. Перевірте фактичний декодер на цільовій системі.
