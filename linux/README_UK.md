# LowTube для Linux — попередня версія

Окремий настільний клієнт на .NET 8 та Avalonia. Підтримуються пошук YouTube, публічні канали, збережені відео й історія, локальні плейлисти, імпорт/експорт бібліотеки, черга з автопереходом, відновлення позиції, відео- та аудіозавантаження через `yt-dlp`, керування `mpv` через приватний Unix socket, три мови інтерфейсу, теми, масштабування відео та шість готових пресетів еквалайзера.

## Потрібно

- .NET 8 runtime для опублікованої збірки або SDK 8 для запуску з вихідного коду;
- `yt-dlp` і `mpv` у `PATH`;
- системні графічні бібліотеки, які потрібні Avalonia/Skia на вибраному дистрибутиві.

Після встановлення потрібних пакетів зберіть і запустіть застосунок:

```sh
./linux/build.sh
dotnet run --project linux/LowTube.Linux/LowTube.Linux.csproj
```

Для публікації framework-dependent збірки виконайте `./linux/publish.sh`; результати з’являться в `linux/LowTube.Linux/publish`. Застосунок використовує системні `yt-dlp` та `mpv`, не завантажує їх автоматично й не передає пошуковий текст через shell.

Налаштування зберігаються у `$XDG_CONFIG_HOME/lowtube/settings.json`, бібліотека — у `$XDG_DATA_HOME/lowtube/library.json` (відповідно `~/.config` та `~/.local/share`, якщо XDG-змінні не задані). Бібліотеку можна експортувати у версійний JSON і злити з іншою копією; імпорт перевіряє межі розміру, тип даних та YouTube-посилання до зміни стану. Файли приватні для поточного користувача.

## Що ще потрібно для повного паритету

Відео відтворюється в окремому вікні `mpv`. Немає входу в Google, приватних підписок, рекомендаційної стрічки, вбудованого відеовіджета, власних кривих еквалайзера, автоматичного оновлення списків у фоні та звіту діагностики Windows-рівня. Якість, FPS, кодек, масштабування, кеш і еквалайзер задаються під час запуску mpv; після їх зміни перезапустіть LowTube. Зміна гучності, мови, теми та поведінки черги застосовується одразу.

`--hwdec=auto-safe` дозволяє mpv обрати безпечний доступний режим, але сам параметр не доводить, що декодування відбувається на GPU. Перевірте фактичний декодер на цільовій системі.

Smoke-тести без графічного середовища запускаються командою `dotnet run --project linux/LowTube.Linux.Tests/LowTube.Linux.Tests.csproj -c Release`. Вони перевіряють сервіси й IPC, але не рендеринг вікна, системні графічні драйвери чи реальне відтворення з YouTube.
