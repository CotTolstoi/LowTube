# LowTube для Linux — початковий перенос

Ця збірка починає нативний Linux-порт окремо від Windows-версії. Поточний зріз містить вікно Avalonia, пошук через `yt-dlp`, окреме вікно `mpv` з керуванням через Unix socket та основні параметри якості, FPS, кодека і кешу. Решта бібліотечних і облікових функцій ще переноситься.

## Потрібно

- .NET SDK 8;
- `yt-dlp` і `mpv` у `PATH`;
- системні графічні бібліотеки, які потрібні Avalonia/Skia на вибраному дистрибутиві.

Після встановлення потрібних пакетів зберіть і запустіть застосунок:

```sh
cd linux/LowTube.Linux
dotnet run
```

Застосунок використовує системні `yt-dlp` та `mpv`, не завантажує їх автоматично й не передає пошуковий текст через shell. Налаштування зберігаються у `$XDG_CONFIG_HOME/lowtube/settings.json` (або `~/.config/lowtube/settings.json`), файл доступний лише поточному користувачу.

## Межі поточного етапу

`mpv` відкривається окремим вікном. UI може ставити відтворення на паузу, зупиняти та змінювати гучність; черга, відновлення позиції, еквалайзер і вбудоване відео ще не перенесені. `--hwdec=auto-safe` дозволяє mpv обрати безпечний доступний режим, але сам параметр не є доказом апаратного декодування. Перевірте фактичний декодер на цільовій системі.
