LowTube 0.8.0 — сесія YouTube, стрічки, типи контенту, плейлисти
Патч для LowTube 0.7.2 Windows x64. Це не збірка Windows 7 x86.

ВСТАНОВЛЕННЯ
Закрий LowTube, розпакуй ZIP у папку з LowTube.exe із заміною файлів.
Запусти START.cmd. Зовнішні компоненти та особисті налаштування не видаляються.

СИНХРОНІЗАЦІЯ
На головному екрані натисни «Синхронізувати». Після натискання програма
без додаткового підтвердження копіює сесію останнього обраного браузера
та профілю, зберігає її та оновлює списки YouTube.
Якщо профіль ще не задано або його папка зникла, використовується перший
автоматично знайдений профіль (запущені браузери стоять першими). Джерело
відображається в журналі. Для вибору конкретного акаунта користуйся
Акаунт -> Підключити YouTube. Закрий вікно акаунта після імпорту: тоді
автоматично завантажуються канали підписок, стрічка підписок і рекомендації.
Кнопка «Скасувати» перериває завантаження; уже збережена сесія залишається.

Google OAuth блок зі скриншота прибрано з доступного інтерфейсу.
«Підписки Google» замінено на «Підписки YouTube» через сесію браузера.
Локальні «Підписки» залишилися окремими, їхній список не перезаписується.
«Рекомендації YouTube» отримуються через сесію з домашньої стрічки YouTube.
Cookies не містять списків підписок чи рекомендацій — списки запитуються
в YouTube після імпорту. Результат залежить від доступності стрічки,
чинності сесії та підтримки поточної сторінки компонентом yt-dlp.
Якщо окрема стрічка не завантажилася, у журналі буде причина. Інші
успішно завантажені списки й сесія зберігаються. Повтори синхронізацію.
Імпорт каналів обмежено 5000 записами. Збережений знімок прив'язаний до
поточного файла сесії: дані попередньої сесії не підмішуються.

ТИПИ КОНТЕНТУ ТА КАНАЛИ
Над списком є: Увесь контент / Відео / Shorts / Прямі трансляції / Плейлисти.
У двох розділах підписок додатково є фільтр за каналом.
Для підписок вибір конкретного типу запитує відповідні вкладки каналів
(videos, shorts, streams, playlists), до 25 записів на канал за сторінку,
два запити одночасно. Для великої кількості каналів це може тривати довго;
вибір одного каналу прискорює завантаження.
У загальній стрічці без типового фільтра локальні підписки використовують
RSS, підписки YouTube — персональну стрічку YouTube.
У пошуку, рекомендаціях та історії фільтр застосовується до доступних
записів поточної сторінки. Порожній результат не означає, що такого
контенту взагалі немає: перейди на наступну сторінку. Пошук плейлистів
і активних трансляцій також передає відповідний фільтр YouTube.
Shorts визначаються за метаданими/посиланням Shorts, а не за тривалістю.
Архіви й заплановані ефіри теж належать до категорії трансляцій.
Стара локальна історія може не мати даних про тип; ці записи лишаються
позначеними як відео до нового відтворення з актуальними метаданими.

ПЛЕЙЛИСТИ
Встав URL https://www.youtube.com/playlist?list=... у пошук або відкрий
картку плейлиста подвійним натисканням / кнопкою «Відео».
Обери перший потрібний ролик і запусти: після його завершення відтвориться
наступний, а наприкінці сторінки завантажиться наступна сторінка плейлиста.
Кнопка «Стоп» скасовує подальший перехід. Запуск відео з іншого розділу
також замінює чергу. Приватні й недоступні ролики можуть перервати чергу.
Завантаження файлів залишається для окремого вибраного ролика: спочатку
відкрий плейлист, вибери ролик, потім натисни «Завантажити».

ТРАНСЛЯЦІЇ Й AUDIO ONLY
Підтримуються доступні потоки YouTube, зокрема HLS, що їх повертає yt-dlp.
Поточний ефір не кешується як звичайний список форматів; новий запуск
не примушує плеєр переходити на нульову позицію. Для ще не розпочатого
ефіру є окреме повідомлення. Доступність перемотування визначає сам ефір.
Обмеження висоти/FPS/кодека залишаються чинними: якщо немає відповідного
формату, їх потрібно змінити вручну.
Якщо окремого звуку немає, Audio only може використати об'єднаний потік
із вимкненою відеодоріжкою. Це може збільшити витрати інтернету.

ВІКНО БЕЗ РАМКИ
Під час перегляду: F4 або правий клік -> «Вікно без рамки» -> «Застосувати».
Зміна лише рамки, пріоритету вікна або швидкості застосовується без
перезавантаження потоку. Налаштування зберігається. Для повернення рамки
відкрий ті самі налаштування. Alt+F4 закриває вікно, F перемикає повний екран.

ПЕРЕВІРКИ
Компіляція C# 5 / .NET Framework 4.8 x64 успішна.
208 перевірок логіки успішні; 337 записів локалізації EN/UK/RU перевірено.
Нові перевірки: типи контенту, канали, плейлисти, параметри рамки,
Audio only для об'єднаного потоку, а також попередні регресійні перевірки.
Windows UI, реальні акаунтні стрічки, живі ефіри й автоматичні переходи
mpv на Windows у середовищі збірки не запускалися: потрібен тест на ПК.
