LowTube 0.11.6 — Windows 10/11 x64 — полная программа без пакетов компонентов

УСТАНОВКА И ОБНОВЛЕНИЕ
Распакуйте весь архив. Для новой установки запустите SETUP.cmd, затем START.cmd.
Требуется .NET Framework 4.8. Установщик здесь называется SETUP.cmd, не setup.exe.
Пакеты yt-dlp, Node.js 22, QuickJS-NG, mpv, FFmpeg и 7-Zip не включены.
При обновлении закройте LowTube и замените файлы в существующей папке, сохранив
папку tools. Повторная установка работающих компонентов не требуется.
Настройки, история и сохранённая сессия остаются в локальных данных Windows.

ЭКВАЛАЙЗЕР
Откройте «Эквалайзер» под «Настройки» в левом меню и включите его.
Пресеты: ровный звук, усиление басов, голос, высокие частоты, рок, классика,
свой. Доступны 10 полос от 31 Гц до 16 кГц, диапазон -12…+12 дБ и предусиление.
Перемещение ползунка выбирает свой пресет; он сохраняется при смене пресетов.
Нажмите «Применить», чтобы сохранить изменения и услышать их в текущем видео
или audio only без перезапуска mpv. Усиление полос снижает входной уровень для
запаса громкости. При искажениях дополнительно уменьшите предусиление.
По умолчанию эквалайзер выключен; при отключении его фильтр не обрабатывает звук.
Он влияет только на воспроизведение, не изменяя скачиваемые файлы.

ДРУГИЕ ВОЗМОЖНОСТИ
Сохранены отдельный плеер, режим поверх окон и без рамки, компактный audio only,
кеш форматов, настройки декодера, качества и буфера по F4 / правой кнопке мыши.
Изменение качества использует тот же mpv; смена рендера может его перезапустить.
Загрузка доступных 1440p/2160p и аудио, подписки, рекомендации, трансляции,
плейлисты, фильтры каналов и контента, локальная история и фоновый кеш списков.
«Синхронизировать» импортирует YouTube-сессию поддерживаемого браузера.
Ограничения браузера могут помешать импорту; работа со всеми браузерами не
гарантируется. Сессия может потребовать обновления. Не передавайте файлы cookies.
Кнопки предыдущей и следующей страницы находятся рядом. В настройках можно
ввести 1–250 элементов на страницу, выбрать язык и тему. Для новой установки
язык по умолчанию — английский, JavaScript-движок — Node.js 22.
Скрипты дополнительных движков требуют их отдельной установки.

ДИАГНОСТИКА
Отчёт запуска доступен в настройках. START_PLAYBACK_DEBUG.cmd включает журнал,
F8 отмечает проблему. Исходники включены; BUILD.cmd пересобирает программу.
Статус разработки и рекомендации по проверкам см. в
docs/development/PROJECT_STATE_UK.md. Исторические материалы находятся в docs/legacy.
