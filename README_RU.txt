LowTube 0.12.3 — пакет для бета-тестеров

1. Запустите SETUP.cmd и разрешите загрузить необходимые компоненты приложения.
2. Запустите LowTube через START.cmd.

В архиве предыдущая версия 0.12.3: отдельное окно видеоплеера, компактное окно аудио, настройки видео и диагностика плеера в панели управления, эквалайзер.

Загружаемые установщиком компоненты и личные данные исключены. Файлов браузерной сессии, cookies, локальных данных приложения и профилей пользователей в архиве нет.
