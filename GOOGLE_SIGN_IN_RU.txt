ВХОД GOOGLE — LOWTUBE 0.5
Сборка поддерживает официальный Google OAuth для ПК в обычном браузере.
Готового зарегистрированного Client ID в ней нет. Перед первым входом
нужно однократно настроить собственный проект Google Cloud.

1. Открой https://console.cloud.google.com/ и создай или выбери проект.
2. APIs & Services > Library: включи YouTube Data API v3.
3. Открой Google Auth Platform. Заполни Branding: название программы и
   контактная почта. В Audience для личного тестирования выбери External /
   Testing и добавь свою почту Google в Test users. Для Workspace доступ
   может ограничивать администратор.
4. В Data Access добавь https://www.googleapis.com/auth/youtube.readonly .
5. Clients > Create client > Desktop app. Скачай JSON клиента.
   Не выбирай Web application, Android или ключ service account.
6. В LowTube: Аккаунт > Импортировать JSON клиента OAuth. Выбери файл.
7. Нажми «Войти через Google». Выбери аккаунт на accounts.google.com
   и разреши чтение YouTube. После перенаправления вернись в LowTube.
8. Открой «Подписки Google» слева. Список каналов читается через
   официальный API, последние публичные видео — из лент каналов.
   Читаются все страницы подписок; показывается до 3000 последних видео.
   Локальные подписки независимы и не перезаписываются.

В проектах Testing обычно нужно повторять вход через семь дней.
Отключённый API, исчерпанная квота, политики администратора или отозванное
разрешение могут блокировать доступ. Используй свой OAuth-проект.
Для широкого распространения нужны соответствующие процедуры публикации
и проверки Google; эта сборка не имеет верификации Google.

OAuth не предоставляет персональную главную ленту, историю просмотров
или адреса скачивания медиа. Рекомендации остаются тематическими;
локальная история — история этого клиента. Прежняя экспериментальная
история YouTube и воспроизведение с аккаунтом доступны через Аккаунт >
Настройки Firefox / cookies. OAuth-токены не передаются в yt-dlp, mpv,
запросы превью или публичных лент каналов.

Токены зашифрованы DPAPI для твоего пользователя Windows в файле
%LOCALAPPDATA%\LowTube\google-session.bin. Настройки клиента —
google-client.json. Пароль вводится только на сайте Google.
Отключение удаляет локальный токен. «Отозвать доступ Google» также
убирает разрешение у этого OAuth-клиента; подписки не меняются.
Разрешения доступны и на https://myaccount.google.com/connections .
Закрытие окна или отмена останавливает вход; ожидание — пять минут.

Полный вход с настоящим Google требует твоего клиента и аккаунта и ещё
не проверен вживую в этой сборке. Локальное перенаправление, state,
PKCE, отмена и компиляция проверены. Подробности — VALIDATION.txt.
