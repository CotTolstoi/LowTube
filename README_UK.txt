LowTube — встановлення для Windows 10/11 x64

1. Розпакуйте весь архів у папку, доступну для запису.
2. Запустіть SETUP.cmd і дочекайтеся завершення. Для завантаження компонентів потрібен інтернет.
3. Запустіть START.cmd. Потрібен .NET Framework 4.8.

Установка має назву SETUP.cmd. Вона завантажує yt-dlp, Node.js, QuickJS-NG, mpv, FFmpeg та 7-Zip. Ці сторонні компоненти не включені до архіву.
Дані користувача зберігаються окремо у %LOCALAPPDATA%\LowTube і не входять до архіву.
BENCHMARK.cmd, HYBRID_EXPERIMENT.cmd і HYBRID_BENCHMARK.cmd запускають окремі додаткові інструменти.
